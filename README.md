# FYRE Academy — Website Starter

A responsive FYRE Academy website with a homepage, learning paths, searchable resource catalog, topic previews, and links to public learning resources.

## Preview

Open `index.html` in any modern web browser. No dependencies or build step required.

## Deploy

Upload the files to any static host (Vercel, Netlify, GitHub Pages, or similar). On Vercel, import the repository and select **Other** as framework; no build command is needed.

## Customize

- Update `courses` in the script at the end of `index.html` to add, edit, or remove resources.
- Replace the placeholder external learning resource links with FYRE's own lessons when ready.
- Brand color: `#ff3e1a`.

## Current scope

This is a functional front-end foundation, not a full LMS. It does not contain account registration, progress persistence, quizzes, certificates, admin dashboards, or a learning backend. Course entries are starter learning roadmaps, not original hosted classes. Job placement is not guaranteed or advertised.
